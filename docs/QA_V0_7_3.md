# v0.7.3 — readable stationary machine indicators

The alternator/motor scene now uses seven fixed-size component callouts instead
of twelve competing numeric labels. All thirteen distinct readings remain:

| Component           | Readings                                |
| ------------------- | --------------------------------------- |
| Stator              | B                                       |
| Collector/converter | emf, current                            |
| Rotor housing       | force magnitude, electromagnetic torque |
| Shaft               | external/load torque, mechanical power  |
| Battery             | SoC, electrical power                   |
| Winding             | temperature, Joule power                |
| Flywheel            | inertia, angular speed                  |

The rotor callout attaches to a stationary point beside the housing, not to the
rotating force-arrow tip. Other anchors are also stationary. Sizes do not depend
on digit count or sign. The scene's intro camera flight is disabled; user camera
controls still work. Opaque surfaces, primary text, quantity-coloured borders and
14 px type (16 px in presentation mode) improve readability. Short, explicit
lines replace clipped prose and duplicated Joule-power text.

Verification:

- 552 unit tests pass; lint, typecheck, formatting and production build pass.
- Seven targeted browser cases pass, covering five-second recordings at 1280 and
  1920 px in both themes and both modes. Text values change while every callout's
  x/y/width/height remains exactly unchanged. All seven remain visible and unclipped.
- Parameter extremes, presentation, fullscreen, view reset, scene overlap limits
  and the existing battery cutoff/recharge scenario pass.
- The first presentation check exposed a pole-S/flywheel conflict at 1280 px.
  Separating the pole label fixed it; the same assertions pass without reducing
  font size or hiding values.
- Full browser CI remains the merge/release gate. Machine equations, battery
  model, integrators and all other simulators are unchanged. Hardware FPS and
  native runtime performance are not remeasured.
